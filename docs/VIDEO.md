# 動画のノイズ除去

日本語 | [English](VIDEO.en.md)

RE-USE Labでは、iPhone上で動画の音声を処理し、映像と組み合わせて保存できます。[ビルド手順](BUILDING.md)に沿ってアプリをインストールし、モデルをダウンロードしてください。

## 動画を選んで処理する

1. 「動画」から写真ライブラリの動画を選びます。ファイルアプリの動画には「ファイル」を使います。
2. 「ANE + GPU」または「MLX GPU」を選び、「ノイズを除去」を押します。
3. 結果の動画を再生し、「ノイズあり／ノイズ除去後」を切り替えて聴き比べます。再生位置は変わりません。一時停止やシーク後にも選択した音声で再生できます。
4. 「写真に保存」で写真ライブラリへ追加するか、「動画を共有」からファイル保存・共有を選びます。

音声だけが必要な場合は「WAVを保存」を使います。「3回でRTFを測る」では、動画から取り出した音声のノイズ除去速度を測定します。表示するRTFには動画の読み込みや書き出し時間を含みません。

## 対応形式と保存形式

- 入力は0.02秒より長く、最大5分の動画です。iPhoneが読み込めるMOV・MP4・M4Vなどの、mono／stereo音声付き動画に対応します。
- 出力はMOVです。元の映像を再エンコードせず、解像度・向き・映像の品質を保持します。元のファイルは変更しません。
- 処理後の音声は16 kHz・mono・Float32 PCMです。元の音声がstereoの場合も、保存する処理後の音声はmonoになります。
- 圧縮音声の動画よりファイルサイズが増える場合があります。共有先にはMOVとPCM音声に対応したアプリを使ってください。
- 音声トラックがない動画や、読み込み・MOV書き出しに対応していない形式では、エラーを表示します。

## 写真へのアクセスと保存場所

写真の選択画面では、選んだ動画だけをアプリへ渡します。「写真に保存」を初めて押したときに、写真への追加を許可する確認が表示されます。許可しない場合も「動画を共有」からファイルへ保存できます。

動画と音声の処理は端末内で行います。写真ライブラリにあるiCloud上の動画は、選択時に端末への取得が必要な場合があります。選択した動画の作業用コピーはアプリのキャッシュに、処理済みMOV・WAV・計測JSONはアプリの書類に保存します。「モデルを削除」でも処理済みファイルは残ります。

長い動画の処理には、元動画のコピーと書き出し用の空き容量が必要です。アプリを前面に表示したまま処理し、完了後に保存・共有してください。
